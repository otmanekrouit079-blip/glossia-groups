# استراتيجية الـ CRO (Conversion Rate Optimization)

## 1) المبدأ العام: بلا سكرول طويل

الموقع خاصو يكون **مضغوط ومركّز**، ماشي صفحة كتطول لعشرة كيلومتر:
- الخدمات والمنتجات كيتعرضو فـ **Carousels أفقية** (Swipe/Scroll جنبي)، ماشي Grid عمودي طويل
- كل Section فالهوم پيج خاصها تكون "Full viewport-ish" — الزبون كيشوف كلشي بسرعة بلا ما يتوه
- الأولوية: الزبون يوصل لـ CTA (حجز) فـ أقل من 3 نقرات

## 2) بنية الهوم پيج (الترتيب المضبوط)

1. **Hero Section** — صورة/فيديو قوي + Headline + CTA "احجز دابا" (فوق الفولد مباشرة)
2. **Trust Bar** — لوگوهات/بادجات صغار (+2000 زبون، تقييم 4.9، منتجات أصلية...)
3. **Services Carousel** — الخدمات الأساسية (حلاقة، لحية، باقة كاملة) بحال كارطات أفقية
4. **Before/After Carousel** — صور قبل/بعد (Social Proof بصري قوي)
5. **How It Works** — 3 خطوات بسيطة (اختار الوقت → أكد → جي فالمحل) — بلا تعقيد
6. **Products Carousel** — منتجات العناية (بحال AliExpress cards: صورة، عنوان، سعر مشطوب، بادج خصم، نجوم)
7. **Testimonials** — تقييمات حقيقية بصور
8. **الفريق** — صور الحلاقين + خبرتهم
9. **FAQ** — إجابة على الاعتراضات (شحال الثمن، واش خاص رانديفو، فين كاين المحل...)
10. **Final CTA** — تذكير قوي + زر حجز

## 3) الأوفرز (Products) — منطق الـ AOV

كل منتج خاصو يبان بـ 3 خيارات (بحال المثال اللي عطيتينا):
- قطعة وحدة — السعر العادي
- 2 قطع — خصم بسيط + "الأكثر طلبا" (بادج)
- 3 قطع — أكبر خصم + "أفضل قيمة" (بادج)

**فصفحة المنتج (Landing Style):**
- Headline قوي بالفايدة (ماشي بالاسم التقني)
- Subheadline يشرح المشكل اللي كيحل
- نجوم + عدد التقييمات فوق مباشرة
- Scarcity: "باقي X فالمخزون" أو "العرض كيسالي فـ [تايمر]"
- CTA واضح: "زيد للطلب" — كيفتح الـ Order Drawer مباشرة
- Sections تحت: الفوايد، كيفاش نستعملو، شهادات، ضمان، FAQ خاص بالمنتج
- تصاوير 3/4 (placeholder دابا) بالتناوب: صورة يمين/نص شمال، مبعد العكس فالسكسيون اللي بعدها

## 4) Order Drawer (بدل Cart Drawer)

بما أن الخلاص فالمحل، الـ Drawer اسمو **"ملخص الطلب ديالك"** ماشي "Cart":
- كيبان مباشرة ملي الزبون يضغط "زيد للطلب"
- فيه المنتج المختار + الأوفر
- **Cross-sells**: منتجات آخرين ("زيد معاها ب...") — بحال AliExpress
- زر "كمّل الحجز" → كيوديه لفلو الحجز (تاريخ + وقت + معلومات)

## 5) فلو الحجز (Booking Popup/Page)

1. اختيار الخدمة (إلا جا من صفحة خدمة) أو تخطي (إلا جا من منتج بلا حجز)
2. اختيار الفرع (إلا كاينين عدة فروع)
3. اختيار التاريخ (Calendar بسيط، الأيام الفارغين واضحين)
4. اختيار الوقت (Slots متاحة فقط)
5. الاسم + رقم الهاتف (validation مغربي: `06XXXXXXXX` / `07XXXXXXXX`)
6. ملخص: الخدمة/المنتجات + المبلغ الإجمالي + "الخلاص فالمحل"
7. تأكيد → صفحة شكر + رسالة "غاتوصلك رسالة تأكيد"

## 6) Micro-Upsell بعد التأكيد (اختياري قوي)

بعد ما يأكد الزبون الحجز، تبان Popup صغيرة 10-15 ثانية:
"زيد [منتج تكميلي] بـ 99 درهم بلاصة [السعر العادي] — غير هاد المرة" — نفس المنطق ديال المثال اللي عندك.

## 7) عناصر الثقة اللي خاصهم يبانو فكل صفحة

- بادج "خلاص فالمحل — بلا مخاطرة" (بدل بادج COD)
- بادج "منتجات أصلية 100%"
- تقييمات فوق الفولد
- رقم واتساب/هاتف باين فالهيدر للتواصل السريع
