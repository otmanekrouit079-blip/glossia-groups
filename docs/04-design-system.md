# نظام التصميم — GLOSSIA GROUP

## 1) الاتجاه العام

مزيج بين **هوية Barbershop راقية** (Black + Brass/Gold) و**طاقة AliExpress** (بادجات، Urgency، كارطات جذابة، ألوان تحويل قوية). ماشي ديزاين بارد ومينيمال بزاف — خاصو يحس بالحياة والحركة.

## 2) الألوان

| الاستعمال | اللون | Hex |
|---|---|---|
| أساسي غامق (Header, Footer, Sections قوية) | Ink Black | `#141414` |
| خلفية عامة | Off-white دافئ | `#FAF7F2` |
| أساسي (البراند) | Brass Gold | `#B8863B` |
| ثانوي (Urgency/CTA) | Ember Red | `#D8432E` |
| نجاح/متاح | Deep Green | `#3D7A57` |
| نص أساسي | `#1E1E1C` |
| نص ثانوي | `#6E6A63` |
| Borders | `#E6E0D4` |

**قاعدة:** الأزرار المهمة (Add to order, احجز دابا) = Ember Red (كيجذب العين، مجرب فالتحويل). البراند (Header, Logo, أكسنطات) = Brass Gold. خلفيات داكنة (Hero, Footer) = Ink Black.

## 3) التايبوغرافي

- **Headings (عربي):** خط عربي قوي وواضح — `Tajawal` (Bold/ExtraBold) من Google Fonts
- **Body (عربي):** `Tajawal` (Regular/Medium) — سهل القراءة، مدعوم مزيان
- **أرقام/أسعار:** خط Latin واضح للأرقام — `Inter` (يبقى الرقم واضح حتى فالنص العربي)

## 4) مبدأ "بلا سكرول طويل"

- كل Section عرضها الكامل ديال الشاشة، ارتفاعها محسوب (ماشي طويلة بزاف)
- المنتجات/الخدمات = `overflow-x: auto` (Horizontal scroll/Carousel) بدل Grid طويل عمودي
- استعمل Snap scrolling (`scroll-snap-type`) باش يحس المستخدم بالتحكم
- فالموبايل: الكارط الواحد ياخد ~85% ديال العرض، باش يبان جزء من التالي (كيشجع السكرول)

## 5) الكومپوننتات الأساسية

### Header
```
[لوگو GLOSSIA GROUP]  [الرئيسية | الخدمات | المتجر | من نحن | تواصل]  [احجز دابا]
```
- Sticky، خلفية بيضاء/شفافة فوق الهيرو، تولي Solid ملي يبدا السكرول
- زر "احجز دابا" دايما باين بلون Ember Red

### Product Card (بحال AliExpress)
- صورة المنتج (Square، بادج خصم فالزاوية "خصم 30%")
- عنوان قصير قوي بالفايدة
- ⭐⭐⭐⭐⭐ (4.8) + "(312 تقييم)"
- السعر: مشطوب (السعر العادي) + السعر الحالي بلون بارز
- بادج Scarcity: "باقي 8 فالمخزون" (لون Ember Red)
- زر "زيد للطلب"

### Booking Widget
- Calendar بسيط (Grid 7 أيام)، الأيام الفارغة بلون فاتح، الممتلئة معطّلة
- Slots الوقت بحال Chips قابلين للضغط
- كل خطوة كتبان بعد اللي قبلها (Progressive disclosure) — ماشي كلشي دفعة وحدة

### Order Drawer
- كيبان من اليمين (RTL) بحركة انزلاق
- Header: "ملخص الطلب ديالك"
- المنتج المختار + الكمية + السعر
- Section "زيد معاها" (Cross-sells) — كارطات صغار أفقية
- زر تحت: "كمّل الحجز" (Full width, Ember Red)

## 6) أنيميشن وحركة

- Fade-in خفيف عند الظهور (Intersection Observer) — بلا مبالغة
- Hover على الكارطات: `scale(1.02)` + shadow خفيف
- الـ CTA الرئيسي: نبضة خفيفة (`pulse`) باش يجذب العين بلا ما يكون مزعج

## 7) الريسپونسيفيتي

- Mobile-first إجباري (أغلب الترافيك من Snapchat/TikTok = موبايل)
- Breakpoints: `sm:640px md:768px lg:1024px xl:1280px`
- الهيدر يولي Hamburger menu تحت `md`
- الصور: `next/image` مع `sizes` محسوبة مزيان لكل breakpoint
