# كتالوگ المنتجات — بنية الصفحات

## 1) صفحة المتجر (`/shop`)

- Header بسيط: "متجر GLOSSIA — عناية رجالية أصلية"
- Filters بسيطة (الكل / عناية بالشعر / عناية بالبشرة) — Chips أفقية
- المنتجات فـ Grid (2 columns فالموبايل، 3-4 فالديسكتوب) — هنا Grid عادي مقبول لأن الهدف تصفح، ماشي Hero page
- كل منتج = Product Card (شوف `04-design-system.md`)

## 2) صفحة منتج (`/shop/[slug]`) — بنية Landing Page كاملة

هاد الصفحة هي الأهم للتحويل، خاصها بنية كاملة (بحال Landing Page ماشي غير صفحة منتج):

1. **Hero المنتج**
   - صورة/گاليري (يمين فالديسكتوب) + معلومات (شمال): عنوان قوي، subheadline بالفايدة، نجوم+تقييمات، اختيار الأوفر (1/2/3 قطع)، CTA "زيد للطلب"
   - Badge Scarcity تحت الـ CTA: "باقي 12 فالمخزون — الطلبات كتزاد بسرعة"

2. **بار الثقة** (تحت الهيرو مباشرة)
   - أيقونات صغار: "منتج أصلي 100%" | "خلاص فالمحل" | "+500 زبون جربوه"

3. **المشكل والحل** (Emotional hook)
   - "واش عندك [المشكل]؟ ماعادش وحدك." — فقرة قصيرة كتحكي بالإيموسيون
   - صورة توضيحية (يسار) + نص (يمين)

4. **كيفاش كيخدم** (Science/Proof)
   - 3-4 نقاط علمية بسيطة (المكونات، كيفاش كيأثرو)
   - أيقونات + عناوين قصار، بلا فقرات طويلة

5. **قبل/بعد أو نتائج** (إلا كاينة)
   - صور/تقييمات مع نتائج ملموسة

6. **شهادات الزبناء** (Carousel أفقي)
   - صورة + اسم + تقييم + تعليق قصير

7. **الأوفرز بالتفصيل** (تكرار الاختيار، لأن بعض الزوار كيوصلو هنا مباشرة بالسكرول)
   ```
   قطعة وحدة — 199 DH
   2 قطع — 279 DH  [الأكثر طلبا]
   3 قطع — 349 DH  [أفضل قيمة — وفر 20%]
   ```

8. **FAQ خاص بالمنتج**
   - "شحال كنستعملو؟" / "واش آمن؟" / "شحال كيبان المفعول؟"

9. **CTA أخير** — تكرار زر "زيد للطلب" فآخر الصفحة

## 3) بنية البيانات (Product Model)

```python
class Product(Base):
    id: UUID
    slug: str
    name: str                    # "علكات البيوتين ضد تساقط الشعر"
    short_description: str       # subheadline
    long_description: str        # للـ sections
    images: list[str]
    price_1: Decimal             # 199
    price_2: Decimal             # 279 (2 قطع)
    price_3: Decimal             # 349 (3 قطع)
    stock: int
    rating: float                # 4.8
    review_count: int
    is_active: bool
    category: str
```

## 4) Cross-sells

كل منتج عندو `related_products: list[Product.id]` — كيبانو فالـ Order Drawer ملي الزبون يزيد المنتج الأساسي.

## 5) صفحات إضافية مطلوبة

- `/about` — قصة GLOSSIA، الرؤية، الفريق (بنفس مبدأ الثقة والإيموسيون)
- `/contact` — خريطة الفروع + رقم واتساب + فورم تواصل بسيط
- `/services` — نفس منطق `/shop` لكن للخدمات
- Footer: كل اللينكات (الصفحات + الفروع + سوسيال ميديا + سياسة الخصوصية)
